orderflow-api

An order management HTTP API with JWT roles, a validated status workflow, and idempotent order creation.

API reference Source

What it covers

Auth

Register and log in. Access tokens carry USER or ADMIN, and every protected route checks the account still exists.

Orders

Create an order, page and filter it, then move it through CREATED, PAID, SHIPPED, DELIVERED, or CANCELLED.

Reliability

Idempotency-Key on create, optimistic locking on stock, Flyway migrations, and RFC 7807 errors.

Status workflow

CREATED → PAID → SHIPPED → DELIVERED

CREATED or PAID can also move to CANCELLED. Cancelling puts the stock back. Customers can pay or cancel their own orders. Shipping and delivery are ADMIN actions.
